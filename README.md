# XRegion-EC2 Antigravity Plan — Upgraded

This package contains:

- complete XRegion-EC2 implementation plan
- root `AGENTS.md`
- Antigravity workspace rules
- 5 reusable workspace skills
- setup guide

## Install

Copy these into the root of your new project:

```text
AGENTS.md
ANTIGRAVITY_SETUP.md
plan/
.agents/
```

Then open the entire project root in Antigravity.

Start with the prompt in `ANTIGRAVITY_SETUP.md`.

## Workspace skills

```text
.agents/skills/implement-frontend-page/SKILL.md
.agents/skills/implement-api/SKILL.md
.agents/skills/review-code/SKILL.md
.agents/skills/verify-project/SKILL.md
.agents/skills/deploy-xregion/SKILL.md
```

Do not ask the agent to implement every phase in one run.
